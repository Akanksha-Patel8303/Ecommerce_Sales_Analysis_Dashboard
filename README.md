# Ecommerce Sales Analysis Dashboard

## Overview
An interactive **Ecommerce Sales Analysis Dashboard** built with **Microsoft Power BI** to analyze sales performance, profitability, and customer trends.

## Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Data Visualization

## 📌 Key Performance Indicators (KPIs)

|      KPI     |   Value   |

| Total Amount | 438K |
| Total Quantity | 5,615 |
| Total Profit | 37K |
|    AOV      | 121K |

## Key Analysis
- Monthly Profit Analysis
- Sub-Category Profitability
- Category-wise Quantity
- Payment Mode Analysis
- State-wise Sales
- Customer-wise Sales

## Objective
To transform ecommerce data into an interactive dashboard that provides clear insights into **sales, profit, products, customers, and payment patterns**.
